# Image Studio

BuildingAI 的 AI 图片生成扩展。模型和密钥由宿主的 AI 模型管理统一配置。

首页主背景为参考截图中的浅冷白 `#F9F9FF`，导航、卡片及控制台保持原有配色。

首页按商业视觉工坊参考设计展示首屏对比、三组四列工具卡片、价值说明和五档套餐示例。12 项精选工具的配图逐一对应参考页面并保存在 `public/images/home-*.jpg`；其余 9 项工具保留在“更多创作工具”中。首屏原图链接返回 403，因此从用户提供的截图提取了同一组前后对比画面，清晰度受截图分辨率限制。图片、套餐及其数值仅为展示示例；实际价格、积分与权益以账户中心为准，生成规格及耗时以所选模型和任务队列为准。

控制台采用 Atelier 暖白工作台布局：固定侧栏、分类工具矩阵、账户积分记录和最近任务队列。工具卡片与快速生图入口直接进入原有工作流，余额和任务均使用真实接口；小屏幕通过菜单抽屉访问完整导航。

控制台的 20 项参考工具配图保存在 `public/images/console-*.jpg`，包含主图、复刻、融合和抠图的双图展示，不依赖外部图床。参考页未提供服装去皱配图，该工具保留原有图片。

宿主的 `/extension/image-studio` 路由使用 `extensions/image-studio/.output/public` 中的构建。后端按请求读取入口 HTML，避免扩展重新构建后仍引用已替换的旧脚本而白屏；部署此后端修复时需重新构建并重启后端一次。
