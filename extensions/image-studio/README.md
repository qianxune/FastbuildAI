# Image Studio

BuildingAI 的 AI 图片生成扩展。模型和密钥由宿主的 AI 模型管理统一配置。

首页、控制台及所有工具页面共用 `src/web/styles/index.css` 中的一套语义颜色 tokens，以商品主图为基准：浅冷白背景 `--background`（`#F9F9FF`）、白色卡片 `--card`、深色主按钮 `--primary`，以及统一的文字、边框、选中态与焦点色。工具样式、素材库、资产库及弹窗只引用共享 tokens，不再单独定义绿、紫、青色主题；成功、警告、错误仍使用对应语义色。商品配色选项、透明棋盘和版式示例不作为界面主题更改。

首页按商业视觉工坊参考设计展示首屏对比、三组四列工具卡片、价值说明和五档套餐示例。12 项精选工具的配图逐一对应参考页面并保存在 `public/images/home-*.jpg`；其余 9 项工具保留在“更多创作工具”中。首屏使用同款香水的干净日常桌面 / 商业光影生成示意图，两张完整方图固定尺寸叠放，滑块仅控制左图的揭示范围，不缩放或重新裁切图片；它们不是实际任务的处理前后结果。图片、套餐及其数值仅为展示示例；实际价格、积分与权益以账户中心为准，生成规格及耗时以所选模型和任务队列为准。

控制台采用 Atelier 工作台布局：固定侧栏、分类工具矩阵、账户积分记录和最近任务队列。工具卡片与快速生图入口直接进入原有工作流，余额和任务均使用真实接口；小屏幕通过菜单抽屉访问完整导航。

控制台的 20 项参考工具配图保存在 `public/images/console-*.jpg`，包含主图、复刻、融合和抠图的双图展示，不依赖外部图床。参考页未提供服装去皱配图，该工具保留原有图片。

电商生图的商品主图、商品详情、爆款复刻、创意生图、多图融合和商品 SKU 图均无需填写商品名称与品牌，表单不再显示这两个输入项。商品信息以参考图片、已确认的描述和创作要求为准；详情规划仍需商品图片、描述及详情模块。接口保留可选的名称与品牌信息以兼容已有任务。

各工具及资产编辑弹窗在未选图时显示大面积浅底虚线上传框；已有图片时改为 100px 缩略图和加号添加块，达到数量上限后隐藏添加块，允许替换的单图入口保留加号替换功能，移除最后一张图片后恢复大上传框。“从素材库选择”使用文件夹图标和下划线文字，位于上传标题行右侧、上传框之外，空态和已选状态位置一致。局部重绘的标注参考图使用相同状态；素材选择、数量限制、替换、拖放、粘贴及禁用逻辑保持不变。素材库管理页保留大上传框用于补充库内图片。

宿主的 `/extension/image-studio` 路由使用 `extensions/image-studio/.output/public` 中的构建。后端按请求读取入口 HTML，避免扩展重新构建后仍引用已替换的旧脚本而白屏；部署此后端修复时需重新构建并重启后端一次。

图片素材不设账号累计张数上限，历史图片不会占用当前任务的选图名额，也不会自动删除。商品主图每次最多选择 5 张，其他工具仍按角色和模型容量校验；单张图片仍限制为 10 MB，素材库每批最多上传或打包下载 40 张。文件解码、用户目录隔离和元数据大小安全检查保持不变；素材分组及创作参考/模特资产资料的独立 40 条限制不在本次图片累计限制调整范围内。此修复需要同时部署前端并构建、重启后端。

我的作品支持按电商生图、AI 修图、服饰穿戴分组多选业务类型，选择后立即生效；组内和跨组均按“任一选中类型”匹配，未选类型或点击“全部”显示所有类型。日期、状态及所属任务继续与类型条件共同筛选。所属任务浮层支持按完整任务 ID、任务名称或业务类型搜索，按创建时间倒序展示有作品的任务，选择后收起；“全部任务”可取消任务限制。修改筛选会回到第一页并清空下载选择，不改变原有受保护图片预览及 ZIP 下载流程。

## 共享主题配色（CTAI-CHG-0061）

全站沿用 `src/web/styles/index.css` 的语义颜色 tokens：大面积画布为冷白 `#F9F9FF`，侧栏、上传空态及次级表面为极浅蓝灰，表单保持白色。精修预览引用 `--background`，不再以 `--muted` 铺满画布。主按钮、图片内容和状态语义色不变，不为单个页面添加独立主题。

## 模特照片检测（CTAI-CHG-0059 首期）

人工上传或从素材库选择照片后，新增模特、更换模特照片或将参考资料改为模特，都由服务端调用腾讯云 IAI `DetectFace` 校验。表单不展示独立检测长说明，仅在授权勾选中确认人物已成年、拥有使用授权并同意将照片发送腾讯云进行人脸检测。已有模特仅修改名称/描述不重新检测，不批量重扫历史，普通商品图和创作参考不做人脸检查。

检测复用当前启用的 COS 配置中的 `accessKey` / `secretKey`，但需在腾讯云另行开通**人脸检测与分析**并为该账号授予 `iai:DetectFace` 权限、确保余额/计费可用；COS 可用不等于 IAI 已开通。服务未配置、权限不足、超时或返回缺失时明确报错，不放行。照片归一化为最长边不超过 2048px 的 JPEG，以 base64 通过签名 HTTPS 请求发送，不生成公开图片链接；单次 15 秒超时、禁止跳转、不自动重试、响应最多 64 KiB。腾讯云调用可能产生独立费用；不调用人脸建库、搜索或身份比对接口。

`MODEL_FACE_POLICY` 位于 `src/api/modules/generation/services/model-face.service.ts`，当前要求：检测到恰好一张人脸，估龄至少 18、综合质量至少 70、清晰度至少 80、上下/左右偏转绝对值不超过 10°、平面旋转不超过 20°、无遮挡口罩、处理后人脸宽高至少 64px。数量检测取最多两张且最小检测面部 34px，避免仅取最大人脸而漏掉普通合照。质量与姿态门槛参考腾讯云 [DetectFace](https://cloud.tencent.com/document/product/867/32800) 和[数据结构](https://cloud.tencent.com/document/api/867/32807)；估龄是风险筛查，不是法定年龄证明，不能保证识别所有未成年人。

定制生成保存请求附带 `generatedFrom` 任务编号，后端验证当前账号已完成的单张、纯文本定制模特任务、受约束的共享提示词模板及归一化结果与实际素材的 SHA-256 一致，才豁免上传检测；不能通过客户端来源标记或借用任务编号跳过校验。原有图片归属、版本冲突、引用保护与 40 条资产资料限额保留。检测通过仅在进程内按配置/图片 hash 缓存 5 分钟、最多 128 项，失败不缓存；不保存估龄或其他人脸属性，重启或过期后再次检测可能产生调用费用。

**首期未实现公众人物/明星脸检测，也不判断肖像权或版权归属，不代表 CTAI-REQ-0056 完整合规验收通过。** 首次部署检测能力需同时发布前端、构建扩展 API 并重启后端；仅调整前端说明无需重启后端。

## 生图功能使用统计（CTAI-REQ-0058 / CTAI-CHG-0069）

仅超级管理员可在 `/extension/image-studio/console/analytics` 看到“使用统计”入口并读取 `/image-studio/consoleapi/analytics`。控制台路由位于共享 `AuthGuard` 内；无登录令牌直接访问时，AuthGuard 先进入扩展公开 `/login` 桥接页，再由顶层窗口跳转宿主 `/login`，并保留完整 `/extension/image-studio/console/...` 查询与锚点。桥接只接受当前扩展控制台内的路径，拒绝外链、路径越界、反斜杠及控制字符，不会渲染统计页面。登录普通用户或身份信息仍在加载时，页面级权限外壳显示“无权限访问”和“返回工作台”，在通过 `isRoot === 1` 前不会挂载统计查询；token 缺失检查也保留为组件隔离防御。页面默认统计上海时区最近 30 天，支持最近 7/30/90 天、自定义日期、按日/按月和 21 个生成业务筛选；日范围最多 366 天，月范围最多 24 个月。

任务数包含筛选区间创建的生成记录；实际生成图片数取持久化 `images` 数组长度；净消耗积分只累计当前 `billingStatus = charged` 的账单金额，`refunded` 单独展示；失败率为失败任务除以完成与失败任务之和，取消任务不进入分母；缺失日期/月补零。趋势与筛选固定采用 `Asia/Shanghai`，功能目录保留未知历史 `toolKey` 为“未知功能”。

接口只返回聚合数据，不返回用户 ID、提示词、错误内容、任务明细、图片 URL 或图片内容，也不建立个人画像。首期没有导出、钻取、实时刷新或新增事实表/物化汇总；数据继续从现有 `ImageGeneration` 记录只读聚合。API 权限、真实账户 401/403/超级管理员读取、真实数据 SQL 对账及浏览器验收仍须在不写数据的单独授权下完成，自动化构建不能替代用户验收。
